# Packaging — ideas y proveedores (para más adelante)
> Notas para cuando se cambie el empaque de los productos. Skill `prospecting` para
> los proveedores. Última actualización: 2026-06-23.

## Situación actual
- Empaque hoy: **bolsas de celofán/polipropileno transparentes, termoselladas**, con el
  logo impreso en negro/dorado ("Betina Potap · Alimentos Naturales · Hecho con Amor").
- Pros: barato, muestra el producto, ya tiene marca.
- Contras para B2B: se ve arrugado/informal, no se para solo, no resellable, **sin info
  obligatoria** (sin TACC, ingredientes, vencimiento, lote) → resta confianza con empresas.

## Ideas de empaque (de más barato a premium)
1. **Faja de papel ("belly band") + etiqueta de info** sobre la bolsa actual → cambio
   más barato e inmediato. Tapa el sello, suma marca + info. **Primer paso.**
2. **Doypack / stand-up pouch con zip** (kraft con ventana). Se para solo, resellable,
   se ve profesional. Comprar genérico + sticker de marca. ← **ELEGIDO para avanzar.**
3. **Sticker de marca + etiqueta de info** en vez de impresión directa (cambiás diseño
   sin reimprimir bolsas).
4. **Porción individual** (bolsita/flow-pack chico) para snacking de escritorio B2B.
5. **Caja kraft + papel manteca + faja** para Welcome Kit / regalo corporativo.
6. **Compostable (PLA/celulosa)** como diferencial sustentable (cuesta algo más).

## Info obligatoria en la etiqueta (clave para vender a empresas)
Denominación del producto · ingredientes · peso neto · fecha de vencimiento · lote ·
datos del elaborador · logo oficial "Sin TACC" si está certificado.
